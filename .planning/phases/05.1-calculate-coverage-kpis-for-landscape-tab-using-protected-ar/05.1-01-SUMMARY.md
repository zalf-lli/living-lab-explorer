# Phase 05.1 Plan 01: Calculate Protected Area Coverage KPIs — Summary

**Calculate coverage KPIs for landscape tab using Phase 5's protected-areas maps.**

## Objective Accomplished

Converted Phase 5's per-LL protected-areas GeoJSON (full, unclipped site extents for map display context) into the two curated KPI slots the landscape tab was missing: `natura2000_ha` and `nature_reserves_ha`. Produced `data/protected_area_kpis.json` with real, clipped, plausible, reproducible coverage values across the 5 Living Labs, and locked the computation in `data-pipeline/python/compute_protected_area_coverage.py`.

## Tasks Executed

### Task 1: Write compute_protected_area_coverage.py ✓

**File:** `data-pipeline/python/compute_protected_area_coverage.py` (200 lines)

**Implementation:**
- Reads Phase 5's per-LL protected-areas GeoJSON (EPSG:4326)
- Validates geometry with `make_valid()` immediately post-read (CLAUDE.md rule)
- Reprojects to EPSG:25832 (UTM 32N, BfN native metric CRS)
- Filters by designation group: `natura2000_ha` ← SCI+SPA rows; `nature_reserves_ha` ← NSG rows
- Dissolves overlapping same-designation polygons with `union_all()` before clipping
- Clips dissolved geometry to LL boundary using `.intersection(ll_geom)` (opposite of Phase 5's D-03 display intent)
- Computes area with `clipped.area / 10_000`, rounded to 1 decimal place (hectares)
- Includes source-sum fields for validation gates: `natura2000_source_sum_ha`, `nature_reserves_source_sum_ha`, feature counts
- Fails loudly with named file error if Phase 5 GeoJSON is missing (D-04 dependency enforcement)
- Supports `--ll SLUG` for dry-run diagnostic mode (prints computed values, does not write)
- Main flow computes all 5 LLs and writes deterministic JSON: `json.dumps(..., sort_keys=True, ensure_ascii=False, indent=2)`

**Acceptance Criteria Met:**
- ✓ Script parses cleanly (ast.parse verified)
- ✓ Contains `EPSG:25832`, does NOT contain `EPSG:3857`
- ✓ `make_valid` appears 1 time
- ✓ `union_all` appears 1 time
- ✓ `sort_keys=True` appears exactly 1 time
- ✓ All three designation literals present: `"Natura 2000 SCI"`, `"Natura 2000 SPA"`, `"Naturschutzgebiet"`
- ✓ Fails with named file + `fetch_protected_areas.py` reference when Phase 5 input missing
- ✓ `--ll rheingau` prints `[dry-run]` without modifying output file
