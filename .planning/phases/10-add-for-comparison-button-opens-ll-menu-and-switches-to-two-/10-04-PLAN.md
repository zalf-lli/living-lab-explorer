## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-10 | Denial of Service (client resource exhaustion) | Two eager `LLMap` mounts (D-23) | accept | Bounded by design: at most two maps, five possible LLs, and the fetch layers already dedupe — `useGeoJSON`'s `cache`/`inflight` and `PMTILES_CACHE` are module-scoped and shared across instances, and the two LLs request different per-LL files. `LLMap` is `React.lazy`, so the second mount reuses the resolved chunk. No new dedupe code is warranted. |
| T-10-11 | Tampering (style/DOM injection via metadata) | `background: ll.outlineColor` accent bar and chips | mitigate | `outlineColor` is set as a React style-object property, not via `dangerouslySetInnerHTML` or a raw CSS string, so React serialises it as a single declaration and a value like `red; background-image:url(...)` cannot break out. The value originates from the committed `ll_metadata.json`, not from user input. |
| T-10-12 | Repudiation / correctness (misleading comparison) | Per-column legends and empty states | mitigate | Each column renders `LLMap`'s own `MapLegend` (D-25) because Phase 7 D-09 scales BORIS colours to per-LL quantile buckets — one shared legend would misrepresent €/m² values. Absent data renders an explicit same-footprint placeholder (D-10) so a gap cannot be misread as an aligned value. |
| T-10-SC | Tampering (supply chain) | npm dependencies | mitigate | Zero packages installed. `git diff --stat app/package.json app/package-lock.json` prints nothing after execution. |
