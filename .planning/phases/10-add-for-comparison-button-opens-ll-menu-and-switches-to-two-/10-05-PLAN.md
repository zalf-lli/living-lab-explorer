<objective>
Give comparison mode its own control bar: change partner, swap sides, leave.

Purpose: D-14 makes the bar the single home for every comparison control, which is why the columns
stay chrome-free (D-15) and why the A/B switcher is hidden while comparing (D-02 — layout A's 42/58
split is unusable at half width). This plan closes the loop opened in plan 03: a user can now enter,
re-target, reverse and leave comparison entirely through the UI, with no hand-edited URLs.
Output: `ComparisonBar` plus the swap and exit navigation handlers, swapped into `LayoutSwitcher`'s
DOM slot whenever comparison is active.
</objective>

`const { t } = useTranslation()` inside the component. No new colours: everything comes from `C` in

- `handleSwap` — clone `searchParams`, `next.set('compare', ll.slug)`, then
  `navigate({ pathname: `/ll/${partner.slug}`, search: next.toString() })`. The former partner becomes

  pathname is unchanged (the route slug is already the primary LL), and `?layout` survives, so the
  user lands back on whichever layout they had (D-02).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL hash params → swap/exit navigation targets | `searchParams` is user-controllable; it is cloned into a `URLSearchParams` object rather than string-concatenated. |
| Metadata `slug` values → pathname construction | `ll.slug` and `partner.slug` come from validated metadata objects (plan 03's identity check), never from raw URL text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-13 | Tampering (param injection) | `handleSwap` / `handleExit` | mitigate | Both build the query string via `new URLSearchParams(searchParams)` + `set`/`delete` and `toString()`, which percent-encodes values — no manual string concatenation of untrusted text into the URL. The `compare` value written by `handleSwap` is `ll.slug`, taken from validated metadata. |
| T-10-14 | Spoofing (open redirect) | `navigate({ pathname })` in `handleSwap` | mitigate | The pathname is built as `/ll/${partner.slug}` where `partner` passed plan 03's `partner.slug === compareSlug` own-property check, so only one of the five known slugs can appear. It is a relative in-app path under `HashRouter`; no absolute URL or host is ever constructed. |
| T-10-15 | Tampering (XSS) | Bar labels and LL names | mitigate | All bar copy comes from `t()` and LL names from metadata, rendered as JSX text children (auto-escaped). `ComparisonBar` introduces no `dangerouslySetInnerHTML` — assert `grep -c dangerouslySetInnerHTML` inside the component returns 0. |
| T-10-SC | Tampering (supply chain) | npm dependencies | mitigate | Zero packages installed. `git diff --stat app/package.json app/package-lock.json` prints nothing after execution. |
</threat_model>
