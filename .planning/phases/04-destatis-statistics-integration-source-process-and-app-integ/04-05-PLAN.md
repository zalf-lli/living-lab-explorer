<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `ll_metadata.json` -> React render | Fetched-once static JSON rendered directly into the DOM via JSX text interpolation (not `dangerouslySetInnerHTML`) |
| StatPanel -> external GENESIS link | `target="_blank"` outbound link to an external government domain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Tampering | Reflected XSS via `target="_blank"` without `rel="noopener"` | mitigate | `rel="noopener noreferrer"` is applied on every StatPanel source link, matching the existing `LLMap` `InfoRow` pattern |
| T-04-12 | Information Disclosure | Rendering numeric statistics values | accept | Data is public government statistics, not sensitive; no PII involved |
| T-04-13 | Tampering | JSX text interpolation of `field.value`/`field.unit` | accept | React JSX text nodes are auto-escaped; no `dangerouslySetInnerHTML` is used in `StatPanel` |
</threat_model>
