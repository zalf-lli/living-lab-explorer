`data-pipeline/python/fetch_destatis.py`: credentials must move from the POST body into HTTP
headers, and the base host must move from `www-genesis.destatis.de` to `genesis.destatis.de`. Add a

silently returning all-null data. Then, using one real live response, empirically confirm (not

against helloworld/logincheck" recommendation, before any bulk fetch or table verification is
attempted.

the regional-key assumption (Pitfall 4 / Assumption A1 in 04-RESEARCH.md) is confirmed or corrected
with empirical evidence recorded in the file itself.
