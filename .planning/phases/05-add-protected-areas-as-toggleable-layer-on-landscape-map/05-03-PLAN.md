| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-10 | Tampering | `bindProtectedAreasTooltip` | mitigate | All values reach the DOM via `createTooltipRow`, which assigns `textContent`; template strings with `innerHTML` are prohibited, since BfN free-text fields would otherwise be a stored-XSS sink |

| T-05-12 | Denial of Service | Client rendering at 311k vertices | mitigate | `L.canvas({ padding: 0.5 })` renderer; lazy fetch means the cost is only paid when the user opts in; the toggle can be switched off to recover instantly |
