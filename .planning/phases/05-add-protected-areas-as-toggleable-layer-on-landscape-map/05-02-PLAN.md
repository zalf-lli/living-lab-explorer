<objective>
Register the protected-areas layer as an independent map overlay, establish a single source of
truth for its palette and labels, and add every bilingual string it needs — without touching
`LLMap`. Correct the phase artefacts where research disproved them.

Purpose: D-05 requires an independent toggle that is not forced along with land-use; D-06 requires
it to render on top of land-use; both only make sense if protected areas can be displayed at the
same time as a thematic layer, which the exclusive `LayerTabs` control cannot express.
Output: an `OVERLAYS` registry plus `PROTECTED_AREAS_LEGEND` in `layers.js`, ten new i18n keys in
both languages, and a corrected `05-UI-SPEC.md`.
