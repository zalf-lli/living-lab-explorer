<objective>
Restructure the app's exclusive layer tabs so crop types live on `agriculture` and land cover fills `landscape`, make `landscape` the landing default, and fix the blocker that prevents any per-Living-Lab raster from resolving.

Purpose: D-01/D-02/D-03/D-19 restructure the tabs; D-20/D-21 reuse the existing raster component; D-23 changes the default view; D-24 keeps both tabs freely switchable. The blocker: `resolveLayerAsset()` returns a fixed `pmtilesUrl` for raster layers and ignores `slug` entirely, and `RasterPmtilesLayer` is never handed a slug — so the five per-LL files from 06-02 cannot be addressed.
Output: A working landscape land cover tab, a renamed agriculture tab, and slug-aware raster resolution that leaves the crop-types scalar path intact.
</objective>
