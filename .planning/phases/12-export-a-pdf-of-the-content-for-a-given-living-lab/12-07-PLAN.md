<objective>
Build the non-map content of every tab section: the KPI table, the two narrative text slots, and
the chart.

D-06 is the governing constraint: charts re-plot the existing Phase 9 chart JSON contract rather
than recomputing anything, so the PDF and the live site can never disagree. D-10 requires each tab
section to carry everything the corresponding `LLDetail.jsx` tab shows — KPI values, map, chart, and
both `about` and `challenges` narrative blocks. This plan covers all of that except the map.

RESEARCH.md Pitfall 2 is a real, already-observable data gap rather than a hypothetical: several
Living Labs have empty narrative slots today (`havellandisches-luch`'s `landscape.about`,
`landscape.challenges` and `economic.challenges` are all empty in `data/ll_content.json`), and
`generate_metadata.py` normalizes those to `null`. A naive two-slot layout would print an empty box
beside real text. The null path is therefore a first-class case here, not an afterthought.

Purpose: the textual and quantitative body of the report.
Output: one R module and an Rscript gate covering all fifty (Living Lab, tab) combinations.
</objective>

`ll_kpi_df(slug, tab, lang)` returns one row per entry of `ll_lab(slug)$kpiByTab[[tab]]`, in the
metadata's own order (that order is already the curated per-tab manifest order the web app renders,
so do not re-sort). Each row has:
- `label`: `ll_str(paste0("kpi.", key), lang)` — the same indicator label the app shows.
- `value`: the formatted number, or the not-available marker described below.
- `unit`: the row's `unit[[lang]]`, or an empty string when absent.

Format numbers the way `StatPanel.jsx` does, so the PDF and the site never disagree on a digit
group separator or decimal mark: locale `de-DE` for German and `en-US` for English. In R that means
`format(x, big.mark = ".", decimal.mark = ",")` for German and `big.mark = ","`,
`decimal.mark = "."` for English, with the same rounding StatPanel applies. Read StatPanel's actual
formatting branch and reproduce it rather than inventing a rounding rule.

For a `null` value, put `ll_str("report.noData", lang)` in the `value` column. Six of the seventeen
curated KPI slots are genuinely null today (STATE.md records them: `n_surplus_kg_ha`,
`p_surplus_kg_ha`, `agr_ch4_kt`, `agr_n2o_kt`, `natura2000_ha`, `nature_reserves_ha`) — a blank cell
in a printed table reads as a formatting bug, an explicit marker reads as information.

For climate rows carrying `delta` / `deltaUnit` / `deltaHorizon`, append the delta to the `value`
cell in the same two-line shape `StatPanel` uses for its D-20 delta tile, so the printed KPI carries
the same information as the on-screen one.

`ll_narrative(slug, tab, slot, lang)` returns
`ll_lab(slug)$narrativeByTab[[tab]][[slot]][[lang]]`, defensively returning `NULL` when any level of
that path is absent, when the value is `NA`, or when it trims to an empty string. `slot` must be
`"about"` or `"challenges"`; anything else stops. Returning `NULL` rather than `""` is what lets
`template.qmd` omit the slot entirely instead of allocating an empty box — mirroring how
`TextBlock.jsx` already tolerates an `undefined` text prop in the live UI.

Do not touch `data/ll_content.json` at any point. CLAUDE.md marks it human-owned and never written
by pipeline scripts; this module reads only the published `app/public/data/ll_metadata.json`.

  `getSoilColor`'s three tiers from `ll_tokens()$palettes$soil`: the named `groups` map first, then
