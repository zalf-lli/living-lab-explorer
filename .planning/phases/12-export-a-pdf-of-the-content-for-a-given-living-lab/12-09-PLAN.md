<objective>
Build the eleven raster-backed maps: one crop-type map, one land-cover map, and the climate
section's eight-panel grid.

There is one architectural fact this plan turns on, and it is worth stating plainly because it is
not obvious: the app's raster layers are published as PMTiles, and neither GDAL nor `terra` can read
raster PMTiles. The report therefore renders these maps from the same **source GeoTIFFs** that
`build_pmtiles.py`, `build_land_cover.py` and `build_climate_pmtiles.py` consume — not from the
published tiles. Those source rasters are gitignored but rebuildable, exactly like every other
pipeline intermediate, which is consistent with D-04's "reports are rendered by hand by a developer"
contract.

D-12 fixes the climate scope precisely: baseline plus the 2071-2100 far-horizon change for each of
the four variables, eight maps, not the full variable-by-horizon matrix. The line chart already
covers both future horizons.

Purpose: the remaining eleven of the report's fourteen figures.
Output: one R module and an Rscript gate.
</objective>
