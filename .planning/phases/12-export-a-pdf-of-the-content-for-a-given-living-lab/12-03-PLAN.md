<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Route params / query string → rendered `href` | `ll` is resolved from `bySlug` using a `/ll/:slug` param; STATE.md records that `bySlug` is built with `Object.fromEntries`, so prototype keys have previously resolved truthy here |
| Human-authored `ll_content.json` → `aria-label` / `title` | `ll.name` is authored content that lands in DOM attributes |
| Browser → static host | The anchor requests a same-origin static PDF |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05 | Tampering | `href` / `download` construction in `DownloadReportCTA` | mitigate | The component never renders unless `useReportAvailability` (plan 12-01) returned true, and that hook refuses to probe unless the slug matches `/^[a-z0-9-]+$/` and lang is exactly `en` or `de` — so a traversal-shaped or protocol-shaped slug results in `available === false` and no anchor is emitted at all |
| T-12-12 | Tampering | `ll.name` in `aria-label` / `title` | accept | React escapes interpolated attribute values; `ll.name` reaches the DOM as text, never as HTML, and this is the identical path `ContactManagerButton` already uses for the same field |
| T-12-13 | Spoofing | `<a download>` filename | mitigate | The `download` value is derived from the same validated slug and lang as the href, and is an explicit constant-shaped string — the server cannot suggest an arbitrary filename via Content-Disposition because the attribute takes precedence for same-origin responses |
| T-12-14 | Information disclosure | Link visibility for unpublished reports | mitigate | D-18's fail-closed behaviour means an unpublished or partially-rolled-out report surfaces no link, no path and no error message |
| T-12-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; `app/package.json` dependencies are untouched |
</threat_model>
