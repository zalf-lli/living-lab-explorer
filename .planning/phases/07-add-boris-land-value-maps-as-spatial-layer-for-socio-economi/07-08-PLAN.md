## Trust Boundaries

| pipeline -> BORIS-BB / BORIS-HE WFS | Two unauthenticated outbound HTTPS dependencies; this plan performs the full production fetch |

| `data/geojson/` -> `app/public/data/geojson/` -> `app/dist/` | The publish path that makes the data browser-reachable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03b | DoS | Permanent repository bloat from committed geodata | mitigate | The W-01 per-Living-Lab budget is enforced before any commit; an over-budget file is not committed and the overage is escalated rather than silently re-tuned. The new fixture test makes the budget a permanent regression gate. |
| T-07-05 | Tampering (XSS) | Free-text attributes shipped to the browser | mitigate | The fixture test asserts no non-geometry column beyond the ten-key contract exists, so `bodenrichtwertzoneName` and `bemerkungen` cannot re-enter the published assets. |
| T-07-07 | Spoofing | A string smuggled into a numeric price field | mitigate | The fixture test asserts every `bodenrichtwert` is `None` or a real number and every `has_current_value` is a real boolean, across every feature of every file. |
| T-07-09 | Repudiation | Stale Brandenburg valuations presented as current | mitigate | The no-data share of each Brandenburg fixture is checked against the W-02 figure measured in `07-SPIKE.md`; a drift beyond 5 percentage points is reported rather than accepted. |

| T-07-SC | Tampering | Package installs | accept | Zero new packages; neither `data-pipeline/requirements.txt` nor `app/package.json` changes. |
