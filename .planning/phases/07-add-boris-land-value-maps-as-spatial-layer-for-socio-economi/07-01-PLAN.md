<objective>
Build the low-level BORIS WFS transport module that every later pipeline task in this phase
(probe, semantics validation, production fetch) imports. This is deliberately separated from
`fetch_boris.py` so the Wave-2 spike can measure real server behaviour without the production
fetch existing yet, and so the request-builder XML is unit-testable with zero network access.

Purpose: RESEARCH.md verified that both BORIS endpoints require a WFS 2.0 POST body with
hand-built `fes:Intersects` XML (a first for this repo — Phase 5's BfN work only used GET), that
Brandenburg and Hessen use **different** namespace URIs and **different** native CRSs
(EPSG:25833 vs EPSG:25832), and that the `urn:ogc:def:crs:EPSG::{code}` double-colon form is
mandatory. Getting any of these wrong yields HTTP 200 with zero features and no error message.
Output: `data-pipeline/python/boris_wfs.py` plus `data-pipeline/tests/test_boris_wfs.py`.

  <action>
Create `data-pipeline/python/boris_wfs.py` with a module docstring naming it the shared BORIS-BB/BORIS-HE
WFS transport used by `probe_boris.py` and `fetch_boris.py`. Use `from __future__ import annotations`.
Import `re`, `tempfile`, `time`, `pathlib.Path`, `geopandas as gpd`, `requests`.

Module constants:
- `USER_AGENT = "ll-explorer-pipeline/1.0 (+https://zalf.de)"` (same value `fetch_protected_areas.py` sends).
- `GEOMETRY_PROPERTY = "adv:position"`.
- `ADV_NS = "http://www.adv-online.de/namespaces/adv/gid/7.1"`.
- `STATE_NS`: dict keyed `"bb"` and `"he"`, each `{"prefix": ..., "uri": ...}` using the exact prefix/URI
  pairs in the `<interfaces>` table above. Nothing else may hardcode these strings.

Functions to export:

1. `crs_urn(epsg_code)` returns `f"urn:ogc:def:crs:EPSG::{int(epsg_code)}"`. The double colon before the
   number is mandatory; a single colon returns HTTP 200 with zero features.
2. `polygon_to_gml(polygon, gml_id, srs_name)` — emit `<gml:Polygon gml:id="{gml_id}" srsName="{srs_name}">`
   with a `<gml:exterior><gml:LinearRing><gml:posList>` built from `polygon.exterior.coords` as
   space-separated `x y` pairs formatted with `f"{x:.3f} {y:.3f}"` (projected metres — 1 mm precision is
   ample and keeps the request body bounded). Interior rings are intentionally omitted from the *filter*
   geometry: a filter polygon only needs to be a conservative outer envelope of the LL.
3. `geometry_to_multisurface(geom, srs_name, gml_id="ms1")` — wrap each part of a Polygon/MultiPolygon in
   `<gml:surfaceMember>` inside `<gml:MultiSurface gml:id="{gml_id}" srsName="{srs_name}">`, giving each
   member polygon a unique `gml:id` of the form `p{index}`.
4. `build_intersects_body(state, typename, geom_native, epsg_code, count, startindex=None, result_type=None, geometry_property=GEOMETRY_PROPERTY)`
   — return the full `<wfs:GetFeature service="WFS" version="2.0.0" ...>` XML string. Declare
   `xmlns:wfs`, `xmlns:fes`, `xmlns:gml`, `xmlns:adv`, and the state's own prefix/URI from `STATE_NS[state]`.
   Emit `count="{count}"` always, `startIndex="{startindex}"` only when not None, and
   `resultType="hits"` only when `result_type == "hits"`. Body contains one `<wfs:Query typeNames="{typename}">`
   holding `<fes:Filter><fes:Intersects><fes:ValueReference>{geometry_property}</fes:ValueReference>{multisurface}</fes:Intersects></fes:Filter>`.
   Raise `ValueError` if `state` is not a key of `STATE_NS`.
5. `build_gehoert_zu_filter_body(oid, count=10)` — Brandenburg-only escape hatch verified in RESEARCH.md
   section 4.2. Declares `xmlns:xlink` in addition to the base namespaces, queries
   `br:BR_Bodenrichtwert`, and filters `<fes:PropertyIsEqualTo><fes:ValueReference>br:gehoertZu/@xlink:href</fes:ValueReference><fes:Literal>urn:adv:oid:{oid}</fes:Literal></fes:PropertyIsEqualTo>`.
   Validate `oid` against `^[A-Za-z0-9]+$` and raise `ValueError` otherwise — this is the XML-injection
   guard for the only identifier that is interpolated from server-returned data (threat T-07-02).
6. `http_get(url, params, max_bytes, timeout=300, retries=4)` and
   `http_post(url, body, max_bytes, timeout=300, retries=4)` — both mirror `fetch_protected_areas._get()`
   exactly: exponential `2 ** attempt` backoff on HTTP 403 and on `requests.RequestException`, a
   `RuntimeError` on the final attempt, and a `RuntimeError` when `len(r.content) > max_bytes` naming both
   the actual and the allowed byte count. `http_post` sends `data=body.encode("utf-8")` with headers
   `{"Content-Type": "application/xml", "User-Agent": USER_AGENT}`. Both send the `User-Agent` header.
   Both must call `r.raise_for_status()`.
7. `extract_counts(raw)` — returns `(matched, returned)` as ints by byte-slicing on
   `b'numberMatched="'` and `b'numberReturned="'`, never by parsing XML (threat T-07-01, and the same
   technique `fetch_protected_areas.py` lines 186-191 already uses). Raise `RuntimeError` naming the
   missing marker when either marker is absent, and treat a `numberMatched` value of `b"unknown"` as -1
   rather than crashing.
8. `read_gml_frame(raw, expected_crs, label)` — write `raw` into a `tempfile.TemporaryDirectory()` as
   `{label}.gml` (keeps GDAL's `.gfs` sidecar out of the repo), `gpd.read_file()` it, raise `RuntimeError`
   if `str(frame.crs) != expected_crs` (message must name both the expected and actual CRS and the label —
   this is the 25832/25833 confusion guard, RESEARCH.md Pitfall 4), then set
   `frame.geometry = frame.geometry.make_valid()` per CLAUDE.md and return the frame **still in its native
   CRS** (reprojection is the caller's decision).
9. `parse_property_values(raw, local_name)` — regex over the decoded response text for
   `<[A-Za-z0-9_]+:{local_name}>([^<]*)</` plus the self-closing/`xlink:href` variant
   `<[A-Za-z0-9_]+:{local_name}[^>]*xlink:href="([^"]*)"`, returning the values in first-seen order with
   duplicates removed. Regex, not an XML parser, for the same XXE reason as `extract_counts`.

Do not add any new entry to `data-pipeline/requirements.txt` — RESEARCH.md's Package Legitimacy Audit
confirms this phase introduces zero new packages.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline -> BORIS-BB / BORIS-HE WFS | Unauthenticated outbound HTTPS to two third-party state geoportals; every response byte is untrusted input |
| repo geometry -> hand-built XML request body | `data/ll_boundaries.geojson` coordinates are interpolated into a GML string |
| server-returned OID -> hand-built XML filter | `gehoertZu` OIDs come back from Brandenburg's WFS and are re-sent inside `fes:Literal` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering, DoS | GML response parsing in `read_gml_frame` / `extract_counts` / `parse_property_values` | mitigate | No XML parser is imported in `boris_wfs.py` at all; counts and property values are extracted by byte-slicing and regex. GML is handed to GDAL's driver, which does not resolve external entities by default. Enforced by the `grep -n "xml.etree\|lxml\|minidom"` acceptance criterion. |
| T-07-02 | Tampering | `build_gehoert_zu_filter_body` OID interpolation | mitigate | OID validated against `^[A-Za-z0-9]+$` before interpolation; `ValueError` otherwise. Unit-tested with a `<`/`"` payload. |
| T-07-02b | Tampering | `polygon_to_gml` coordinate interpolation | mitigate | Coordinates are formatted through `f"{x:.3f}"` numeric formatting (not string concatenation) and originate from the repo-owned `data/ll_boundaries.geojson`, never from external input. |
| T-07-03 | DoS | Uncontrolled WFS response size | mitigate | `max_bytes` ceiling is a required parameter of both `http_get` and `http_post`; exceeding it raises `RuntimeError` before the bytes are returned to a caller. |
| T-07-04 | Spoofing, Information disclosure | Endpoint transport | mitigate | Both endpoint URLs are `https://` only and are supplied by the caller from `sources.yaml` (plan 07-06); the module never rewrites a scheme and no credentials exist to leak. |
| T-07-06 | Tampering | CRS confusion between EPSG:25833 (BB) and EPSG:25832 (HE) | mitigate | `read_gml_frame` raises `RuntimeError` naming expected vs. actual CRS; `STATE_NS` is the single source of per-state constants so no caller can conflate them. |
| T-07-SC | Tampering | pip package installs | accept | Zero new packages. 07-RESEARCH.md's Package Legitimacy Audit surface is empty (geopandas/shapely/requests/pyyaml all already in `data-pipeline/requirements.txt`). No install task exists in this phase, so no legitimacy checkpoint is required. |
