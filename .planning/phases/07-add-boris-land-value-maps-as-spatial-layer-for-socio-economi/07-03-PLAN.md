<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline -> BORIS-BB / BORIS-HE WFS | Unauthenticated outbound HTTPS; ~130 MB of GML across ~23 statewide pages plus per-LL zone pages, all untrusted |
| WFS response -> local cache on disk | GML written to `data/_cache/boris/` before GDAL parses it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering, DoS | GML parsing of ~23 statewide pages | mitigate | Parsing goes through `boris_wfs.read_gml_frame` (GDAL driver, no external entity resolution) and `boris_wfs.extract_counts` (byte-slicing). `probe_boris.py` imports no XML parser of its own. |
| T-07-03 | DoS | Statewide BB point fetch (~113,293 records) held in memory | mitigate | Each page is streamed to `data/_cache/boris/bb_points__p{n}.gml` and parsed one page at a time; only the compact join index (OID -> value records) is held in memory and it is persisted to `bb_point_index.json` so downstream work never re-holds the raw pages. `MAX_RESPONSE_BYTES = 209715200` caps every individual request. |
| T-07-03b | DoS | Repository bloat from spike artefacts | mitigate | Every probe output is written under `data/_cache/boris/`, which is covered by the pre-existing `data/_cache/` rule in `.gitignore`; verified by the `git check-ignore` and `git status --porcelain data/geojson app/public/data` acceptance criteria. |
| T-07-02 | Tampering | LL boundary coordinates and server-returned OIDs interpolated into request XML | mitigate | All XML construction is delegated to `boris_wfs.py`'s validated builders (plan 07-01); `probe_boris.py` concatenates no XML itself. |
| T-07-06 | Tampering | CRS confusion 25833 (BB) vs 25832 (HE) | mitigate | `read_gml_frame` is always called with the per-state expected CRS derived from `LL_STATES`, and raises on mismatch. |
| T-07-08 | Repudiation | Spike numbers presented without provenance | mitigate | Every code in the W-03 table records whether it came from `GetPropertyValue` or from the full-fetch fallback; `07-SPIKE.md` states the run date and that all figures were measured live. |
