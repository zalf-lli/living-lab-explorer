harmonization, trimming, and write step, producing `data/geojson/boris-{slug}.geojson` for all five Living

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline -> BORIS-BB / BORIS-HE WFS | Two unauthenticated outbound HTTPS dependencies; roughly 130 MB of statewide GML plus per-Living-Lab zone pages, all untrusted |
| WFS attribute values -> committed GeoJSON -> browser | Values, dates, zone names, and usage codes flow from a third-party service into files the app ships |
| WFS response -> local cache on disk | GML written to `data/_cache/boris/` before GDAL parses it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering, DoS | GML parsing of statewide and per-Living-Lab responses | mitigate | All parsing goes through `boris_wfs.read_gml_frame` (GDAL driver) and `boris_wfs.extract_counts` (byte-slicing); `fetch_boris.py` imports no XML parser. |
