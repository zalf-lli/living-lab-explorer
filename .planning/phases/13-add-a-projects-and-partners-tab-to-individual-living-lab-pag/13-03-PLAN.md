Build `PartnersMap.jsx`: a sibling to `LLMap` (never a branch inside it) that renders the Carto base
map, the Living Lab boundary outline and the outside-boundary mask, plus one declarative
`react-leaflet` marker per partner with coordinates.

ever used `react-leaflet`'s declarative `<Marker>`/`<Tooltip>`, and Leaflet does not open tooltips on
keyboard focus by default (13-RESEARCH.md Pitfall 4). Isolating it in one plan keeps that
first-of-its-kind work at full quality.
Output: one new lazy-loadable component and one CSS class.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hand-authored JSON → Leaflet marker DOM | Partner `name`, `website`, `lat`, `lng` values flow into rendered markup and a navigation call |
| in-app click → external origin | `window.open` hands control to a third-party site in a new browsing context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Tampering | `PartnerMarker` click handler | mitigate | `safeExternalUrl(partner.website)` is resolved before the handler and `window.open` is only called when it returns non-null, so a `javascript:`/`data:` URL in the JSON cannot execute |
| T-13-02 | Information Disclosure | `window.open` target context | mitigate | Third argument is exactly `'noopener,noreferrer'`, blocking reverse tabnabbing and referrer leakage — same convention as every external `<a>` in this codebase |
| T-13-03 | Tampering (XSS) | `L.divIcon({ html })` | mitigate | The `html` value is a constant string literal with zero data interpolation; partner names reach the DOM only as React `<Tooltip>` children and as the `alt` prop, both auto-escaped |
| T-13-08 | Denial of Service | Boundary GeoJSON fetch | mitigate | `useGeoJSON`'s shared URL cache plus explicit loading/error guards; a failed boundary load renders `map.loadError` in place of the map instead of throwing through the component tree |
| T-13-09 | Spoofing | Partner identity claims | accept | JSON presence is the declared permission and authenticity boundary (D-11); content is hand-authored and reviewed via git diff, and the site is public read-only |
| T-13-SC | Tampering | npm installs | mitigate | Zero new packages — `react-leaflet@^5.0.0` and `leaflet@^1.9.4` are already pinned in `app/package.json`; the file must be unchanged by this plan |
</threat_model>
