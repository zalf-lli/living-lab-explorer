<objective>
Make the app's two non-map data surfaces correct for a two-source tab: the chart follows the map mode, and
each KPI tile credits the dataset it actually came from.

Purpose: D-20 makes the chart the one place the app's non-map UI reacts to the sub-tab, and its stated
consequence is that `useChartData`'s URL resolution — currently `LAYER_SOURCE_INDEX.get(layer).id` — must
become mode-aware. `14-RESEARCH.md` Pitfall 2 found a second, separately-caused bug that `14-CONTEXT.md`'s
own file list did not anticipate: `StatPanel`'s per-field provenance fallback is a flat, tab-level lookup, so
the two new computed SQR tiles (which carry no `genesisTable`) would fall through to BUEK250's DOI, licence
and citation. D-05 keeps `StatPanel` itself mode-blind — this is a per-field fix, not a mode prop.

Output: three modified files, each change additive with a default that reproduces today's behaviour exactly.
</objective>
