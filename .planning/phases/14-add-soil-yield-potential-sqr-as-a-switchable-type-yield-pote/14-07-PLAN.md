<objective>
Produce the per-Living-Lab area share of each SQR band, including the Not-rated class, as committed chart
JSON — the artifact both the app's yield-mode bar chart and the PDF report's yield-map bar legend read.

Purpose: D-19 is explicit that this is a hard requirement, not decoration. `legend_bars.R`'s header states
the rule that no statistic is recomputed in R (D-06/T-12-25), and `maps_raster.R`'s
`.ll_climate_band_shares()` is the one documented exception, created only because no committed chart JSON
existed for the climate matrix. This file exists so that exception is not repeated. D-21 includes the
Not-rated class as a grey bar so shares sum to 100 % of the Living Lab and every colour the printed map shows
is explained — which makes this chart's denominator the whole Living Lab, deliberately different from plan
14-05's rated-cells-only mean.

Output: one new script, ten committed chart JSON files, and a consolidated contract-test module covering all
three SQR artifact families.
</objective>

each class's percentage of the **whole Living Lab** in-boundary pixel count. Put a comment on that
