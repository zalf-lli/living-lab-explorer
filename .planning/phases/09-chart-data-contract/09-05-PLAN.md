<objective>
Build the only `line`-variant chart in the phase: per-Living-Lab percent change for all four
CHELSA variables across both future horizons.

Purpose: CHARTS-07 is the requirement that proves `chart_type` is a real discriminator and
not a label - the payload carries `x_axis` plus `lines` and no `series` at all. It is also
the requirement whose original framing was wrong: `data/climate_kpis.json` stores only the
far horizon (`DELTA_HORIZON = "2071_2100"` is hardcoded, and Phase 8's D-21 deliberately
never opened the near horizon), so the 2041-2070 point does not exist anywhere on disk and
must be computed here.

Output: `data-pipeline/python/compute_climate_chart.py` and five committed
`data/charts/chelsa-climate-*.json` files.
</objective>

  area_weighted_mean(raster_path: Path, ll_geom_metric, *, slug: str | None = None) -> float
  Reprojects the whole band to EPSG:25832 BEFORE masking, which is the entire point: CHELSA's
  native grid is 0.0083333 degrees per pixel, a fixed angular size, so a plain masked mean in
