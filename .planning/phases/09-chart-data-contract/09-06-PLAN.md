| repo filesystem -> `app/public/` -> `app/dist/` | `sync_charts()` copies globbed matches into the published web root, and Vite copies that root verbatim into the deployed bundle. A file landing in `app/public/` is a file served to every visitor. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

Task 1's byte-equality assertion additionally proves every published file has a matching in-repo source. |

No PII, no credentials, no internal paths beyond the `source` dataset id. |

| T-09-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task in this plan or phase; `data-pipeline/requirements.txt` and `app/package.json` are unchanged. 09-RESEARCH.md's Package Legitimacy Audit records "Not applicable - zero new external packages". `npm run lint`/`npm run build` use the already-installed dependency tree. |
