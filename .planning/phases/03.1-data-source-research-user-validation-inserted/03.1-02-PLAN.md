<objective>
Fill the Wave 1 catalogue with AI-assisted, evidence-chained source research.

Purpose: Turn the scaffolded stub rows into a decision-ready inventory. Every verified fact (coverage, access method, format, license, cadence) is anchored to a citation URL the AI actually fetched; advisory inferences (LL relevance, pipeline path, complexity) live only in the `(AI) `-prefixed columns. This is the evidence chain that lets Wave 3 reviewers trust the fact columns.

Output:
- `data-pipeline/python/export_source_catalogue.py` — `SOURCES` updated with researched Group B facts + citation URLs and Group C assessments.
- `data/source_catalogue.csv` — regenerated mirror with populated rows.
- `data/variables_catalogue.xlsx` — `source_catalogue` tab re-synced from the CSV, ready for the Wave 3 review session.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03.1-03 | Tampering | Fetched GetCapabilities / API JSON / directory listings | mitigate | Treat all probe responses as inert data: parse XML/JSON for stated facts only, never eval or execute returned content; record the source URL as citation_url so claims are auditable. |
