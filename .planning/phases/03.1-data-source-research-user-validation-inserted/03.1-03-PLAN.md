<objective>
Run the human-in-the-loop review and convert approved sources into integration-ready backlog.

Purpose: Close the discovery loop. End-users decide include/defer/reject per row; the committed mirror is regenerated so the decision record is git-versioned; each approved source becomes a 999.x GSD backlog item carrying an integration sketch detailed enough that a future planner can scope the integration without re-researching.

Output:
- `data/variables_catalogue.xlsx` — reviewed `source_catalogue` tab with Group D decisions filled.
- `data/source_catalogue.csv` — regenerated mirror reflecting final decisions (drift prevention, D-02).
- One 999.x backlog item per approved source, each with a D-11 integration sketch.
- `docs/data-sources.md` — restructured entry-point doc pointing to the catalogue + backlog.
</objective>
