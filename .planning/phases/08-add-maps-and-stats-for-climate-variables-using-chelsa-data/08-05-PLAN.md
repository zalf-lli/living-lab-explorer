<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| i18n resource bundles -> React render | Repo-controlled translation strings are rendered as text children |
| Caller props (`active`, `mode`, `horizon`) -> control state | Values originate from a closed React state machine, not from user text or the URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-10 | Tampering | i18n strings rendered into the DOM | mitigate | All copy is rendered as React text children, which React escapes; no `dangerouslySetInnerHTML` and no `Trans` component with raw HTML is introduced in either new component |
| T-08-06 | Tampering | `variable` / `period` values feeding a raster URL downstream | mitigate | Both controls emit only ids drawn from the arrays their caller passes (`variables`, `horizons`), which 08-10 sources from the codegen'd `CLIMATE_VARIABLES`; no free-text entry point exists, so `resolveLayerAsset` can never receive an arbitrary token |
| T-08-11 | Denial of Service | rapid control toggling triggering repeated raster fetches | mitigate | Both components are stateless and cheap; the fetch-throttling requirement (exactly one raster in flight at a time) is enforced at the consuming layer in 08-10, and is recorded there rather than duplicated here |
| T-08-04 | Information Disclosure | control labels | accept | All labels are public dataset terminology; no user or system data is exposed |
| T-08-SC | Tampering | npm installs | mitigate | This plan installs zero packages — no `package.json` change; both components are hand-rolled inline-style React with no component library, per 08-UI-SPEC.md's `Tool: none` |
</threat_model>
