| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | remote GeoTIFF read in `probe_chelsa.py --align` | mitigate | Metadata-only validation (transform/shape/crs/dtype/nodata asserted identical across the five GCM files) before any downstream use; mismatches reported as `[warn]`, never silently averaged |
| T-08-02 | Tampering | URL and cache-path construction from `{variable}`/`{period}`/`{gcm}`/`{ssp}` tokens | mitigate | Every token validated against explicit `ALLOWED_VARIABLES`/`ALLOWED_PERIODS`/`ALLOWED_GCMS`/`ALLOWED_SSPS` allow-lists before formatting; raise on any token outside them, blocking path traversal and URL injection |
| T-08-03 | Denial of Service | unbounded remote read over `/vsicurl/` | mitigate | Hard 30 s HTTP timeout on probes; 300 s per-read and 5 GB projected-total caps in `--cost`, reported as `[warn]` and carried into `fetch_climate.py` as enforced limits |
| T-08-05 | Spoofing | host impersonation of the CHELSA file server | mitigate | HTTPS enforced by an explicit `https://` prefix check that raises on any other scheme; default certificate validation never disabled (no `verify=False`, no `GDAL_HTTP_UNSAFESSL`) |
| T-08-04 | Information Disclosure | probe output | accept | All probed endpoints are public and unauthenticated; no secrets, tokens or credentials exist on this path |
| T-08-SC | Tampering | pip/npm installs | mitigate | This plan installs zero packages — the light path adds no `requirements.txt` line.
