reads.

  <action>
Create `data-pipeline/python/fetch_climate.py` with an `argparse` entry point exposing
`--layer` (default `chelsa-climate`), `--variable` (repeatable, default all four),
`--period` (repeatable, default all three), and `--dry-run`.

Write a module docstring in the voice of `build_land_cover.py`'s, stating: that this script fetches
Germany-extent windows only (never whole global files), that the twelve outputs under
`data/climate_source/` are gitignored and rebuildable, that the two horizon outputs are *change*
fields rather than absolute futures, and that the OneDrive/non-ASCII-path GDAL `UnicodeDecodeError`
caveat from `build_land_cover.py` applies here too.

Implement these pieces:

1. Token validation. Read `ALLOWED_*` allow-lists from the layer config itself (variables from
   `climate.variables` keys, periods from `climate.horizons` keys plus `baseline`, GCMs from
   `climate.gcms`, scenario from `climate.scenario`). Validate every token before it is formatted
   into a URL or a filesystem path and raise `SystemExit` with the offending token named. Assert
   every constructed URL starts with `https://`. This is the T-08-02 and T-08-05 mitigation and must
   not be skipped for "internal" values.

2. `_read_window(url, bbox)` — open `/vsicurl/{url}` with rasterio, build the window with
   `rasterio.windows.from_bounds(xmin, ymin, xmax, ymax, transform=src.transform)`, read band 1
   within that window only, and return the array plus the windowed transform and the source
   metadata tuple `(crs, dtype, nodata, res)`. Never call `src.read()` without `window=`. Wrap the
   read in a wall-clock timer and raise if it exceeds `climate.budget.max_seconds_per_read`.
   Accumulate a module-level transfer estimate and raise once the running total exceeds
   `climate.budget.max_total_transfer_bytes` (T-08-03).

3. `_assert_grid_alignment(metas)` — given the five per-GCM `(transform, shape, crs)` triples for
   one variable+period, raise a `RuntimeError` naming the differing field if any two disagree. This
   is CLAUDE.md's align-CRS-before-clipping rule extended to "assert grid alignment before
   averaging" (Pitfall 5). Averaging misaligned grids silently produces a plausible-looking but
   wrong field, which is exactly the failure mode this guard exists for.

4. `_multi_model_mean(arrays)` — `numpy.mean(numpy.stack(arrays), axis=0)` over the five aligned
   float arrays, after masking the declared nodata to NaN so nodata never pollutes the mean. Assert
   the result is not all-NaN before returning (the CLAUDE.md `assert len(clipped) > 0` equivalent
   for rasters).

5. Baseline path — one `_read_window` per variable against `climate.baseline_url_template`, no
   averaging (the baseline climatology is model-independent, D-01).

6. Change path — for each variable and each horizon: `_read_window` for all five GCMs against
   `climate.future_url_template`, assert alignment, take the multi-model mean (D-04), then derive
   the change field against that variable's baseline array according to its `change_mode` (D-11):
   `absolute` gives `future - baseline`; `percent` gives `(future - baseline) / baseline * 100.0`
   with a guard that sets the result to nodata wherever the baseline is zero or nodata, so a
   division by a dry cell cannot produce an infinity that later poisons the colour breaks.

7. Writing. Write each result to `data/climate_source/chelsa-{variable}-{period}.tif` as single-band
   float32, `nodata` from `input.nodata`, `compress="deflate"`, `tiled=True`, CRS and transform from
   the windowed read. Create the directory if absent. After each write, compute `_sha256_of` the
   file and compare against `climate.sha256_by_derived`: if a digest is pinned and differs, raise
   with both digests printed; if none is pinned, print an `[info]` line giving the computed digest
   and the exact `sources.yaml` key to paste it into — the same affordance `build_land_cover.py`
   offers for `sha256_by_tile` (T-08-01).

8. Validation. After writing, reopen each output with a climate variant of
   `_validate_source_raster` asserting `count == 1`, `dtypes[0] == 'float32'`, `nodata` equal to
   the declared value, and `crs` equal to `input.crs`. Metadata-only — never read pixels back.

9. Logging. One `[fetch]` line per remote read with variable, period, GCM and elapsed seconds; one
   `[ok]` line per written raster with its path, pixel shape and file size in MB; a final `[ok]`
   summary line giving total remote reads, total wall seconds and the running transfer estimate
   against the W-08 cap.

`--dry-run` performs the allow-list validation, prints every URL it would fetch and the full output
file list, and exits without any network call or write.
