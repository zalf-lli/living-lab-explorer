<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Static PMTiles under `app/public/` -> browser | Published tile bytes are fetched and decoded by the pmtiles JS library and Leaflet |
| Control state -> raster URL | `variable` and `period` values are interpolated into a fetched asset path |
| i18n strings and generated legend data -> DOM | Repo-controlled strings are rendered as text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Tampering | raster URL construction from `variable` and `period` | mitigate | Both values originate from `CLIMATE_VARIABLES` and the fixed horizon token list, never from the URL bar or user text; `resolveLayerAsset` returns null rather than emitting an unresolved brace, and a null URL renders the error badge instead of issuing a request |
| T-08-11 | Denial of Service | rapid variable or period toggling issuing overlapping tile requests | mitigate | Exactly one `RasterPmtilesLayer` is mounted; the remount key covering all three axes unmounts the previous overlay before the next mounts, satisfying 08-UI-SPEC.md's one-raster-in-flight requirement; a cancelled flag prevents a stale resolution from resurrecting a torn-down layer's state |
| T-08-21 | Tampering | malformed or truncated PMTiles response | mitigate | The header read is awaited and a rejection sets the error state and skips adding the overlay, so a bad response surfaces as the bilingual error badge rather than a silently blank map |
| T-08-10 | Tampering | legend labels and notes rendered into the DOM | accept | All strings come from `i18n.js` and the codegen'd `climate_legend.js`, both repo-controlled, and are rendered as React text children; no `dangerouslySetInnerHTML` is introduced |
| T-08-17 | Tampering | hand-edited generated legend module | mitigate | `climate_legend.js` carries the "Do not edit by hand" header and is regenerated by `sync.py`; 08-11's gate re-runs sync and asserts a clean diff |
| T-08-04 | Information Disclosure | rendered climate data | accept | All content derives from public open climate data and is intended for publication |
| T-08-SC | Tampering | npm installs | mitigate | This plan installs zero packages; no `package.json` change, and both new controls are hand-rolled inline-style React per 08-UI-SPEC.md's `Tool: none` |
</threat_model>
