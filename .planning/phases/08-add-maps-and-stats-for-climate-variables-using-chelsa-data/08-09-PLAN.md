<objective>
Retire the Climate tab's two permanently-null Destatis slots, add the four CHELSA-derived ones, and
merge their computed values into `kpiByTab` through a third `source_host` branch — all in one commit.

D-18 is explicit that this is a same-commit requirement, citing the Phase 05.1 D-05 discipline. The
manifest edit, the two locked `tab_counts` dicts in `test_pipeline_outputs.py`, the `source_host`
allow-list tuple and the two now-dead `kpi.*` i18n labels are one atomic change. Splitting them
leaves the suite red and the app rendering a label for a KPI that no longer exists.

D-23 is equally explicit about where the values come from: a new JSON merged at
`generate_metadata.py` build time, never patched into `destatis_ll.json`, which `aggregate_ll()`
destructively regenerates. `_build_kpi_by_tab()` already merges a second computed source on
`source_host == "bfn_wfs"`; this adds a third branch to an existing mechanism rather than inventing
one.

Purpose: make the Climate tab fully CHELSA-sourced and give the two-line tile its data.
Output: an updated manifest, a threaded `generate_metadata.py`, updated test contracts, and a
regenerated `ll_metadata.json`.
</objective>
