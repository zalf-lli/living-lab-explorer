## Locked decisions that constrain the outcome (from 04-CONTEXT.md)

- **D-08:** catalogue group `Environment` splits three ways across tabs; `groundwater_nitrate_mg_l`
  is the sole Environment variable assigned to the **Soil** tab.
- **D-09:** the curated KPI set is a fixed, hand-picked 17 variables with fixed per-tab counts
  `{landuse:4, soil:3, climate:2, landscape:4, economic:4}`. The counts never change. A slot's
  `variable_key` may change only via the D-14 substitution mechanism.
- **D-14:** if a picked table fails verification, swap in the next-best variable **from the same
  catalogue group** rather than leaving the slot empty. This is the ONLY sanctioned route to a
  repurpose, and it is why a repurposed slot needs a catalogue row in the `Environment` group.
- **D-15:** Regionalstatistik.de is an in-scope second host.
- 04-07's **same-real-world-quantity rule:** a table may only fill a slot if it measures the same
  real-world quantity the slot declares. A volume in 1000 m3 can never fill a concentration slot in
  mg NO3/l. This rule is not negotiable and Task 2 must not weaken it.
